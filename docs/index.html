Latent state-space models

Cross-asset market regime detection

A neural stochastic differential equation, observed through a differentiable extended Kalman filter, applied to thirty years of yields, credit, volatility and macro data. The model was trained in PyTorch. Everything on this page runs in your browser, from reading the dataset to filtering the whole sample and clustering the result. You can also upload your own CSV below and run the same filter on it.

Withhold series

Hide a series from the filter and run it again. The mask enters the Kalman gain directly, so the state is inferred from whatever is left. It is the same mechanism that handles genuinely missing data, such as the TED spread after it was discontinued.

Agreement with the Python implementation

—Regime count chosen by BIC in this run

The repository ships the filtered trajectory and the regime labels that the Python pipeline produced. This page recomputes both from the raw data and compares them, so a disagreement between the two implementations would show up here rather than go unnoticed.

Trained in PyTorch at double precision. The browser implementation is a direct port: both networks are linear, tanh, linear, so the Jacobians the filter needs are written out by hand rather than differentiated, and they agree with the Python version to seven decimal places.

Source, tests and the full write-up are in the repository.
