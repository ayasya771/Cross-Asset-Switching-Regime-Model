Withhold features

Uncheck a series to hide it from the filter entirely. The mask propagates into the Kalman gain, so the state is inferred from whatever remains. This is the same machinery that absorbs genuinely missing data such as the TED spread after 2022.

The repository ships the filtered trajectory and the regime labels produced by the Python pipeline. This page recomputes both from the raw dataset and compares, so any divergence between the two implementations is visible rather than assumed.

Trained with PyTorch, float64 throughout. Inference here is a direct port: the Jacobians the filter needs are written analytically, since both networks are linear–tanh–linear. Source, tests and the full report are in the repository.
